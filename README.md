# mcmd

mcmd is a small command-line tool written in rust that opens multiple command prompt windows at once. That's it.

# Usage
```mcmd <int>```

```<int>``` - the number of cmd windows to open 

## Adding to PATH 
1. Search "Edit the system environment variables" in windows search menu
2. Click "Environment Variables" in the bottom right
3. Click on path and trhen click Edit
4. Click new and enter directory that mcmd.exe lives in (not the exe, the directory)

## Why?
I wanted to experiment with Rust and wanted an easier way to open multiple cmd windows
